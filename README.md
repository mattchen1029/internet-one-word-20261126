Entry for the make.fun competition [The Internet in One Word](https://make.fun/bounty/u-ronigrv-the-internet-in-one-word-e388f33b).

`main.py` writes one word describing the whole internet — a single word,
1 to 30 characters — to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`).

The word:

> unhinged

Run it with:

```sh
python3 main.py
```
